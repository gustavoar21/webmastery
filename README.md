# Webmastry

A polished one-page marketing website built as a lightweight static app.

## Run locally

Open `index.html` directly in a browser, or run a local server from this folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files

- `index.html` — page structure
- `styles.css` — branding and layout styles
- `script.js` — small page enhancements
